LAB LOGO SET — from the original illustration
=============================================

What was done
-------------
The original scan had its gray ground and circuit-board lines removed, the halftone
noise cleaned, and the artwork traced into vector layers (tube fills, blue tubes,
pink digits with their black offset shadows, red/pink nodes as true circles, and the
base slab as a clean polygon). Everything scales without pixelation.

Files
-----
svg/                       vector masters
png/                       raster exports (2048 px logos, 1024 px icons, favicons 16-512)
cleaned-raster/            the original with background removed, no tracing (transparent PNG, 3x)

logo-primary               full composition (head, base and floating digits), transparent
logo-primary-on-white / -on-lavender   same, on a ground
logo-head-only             head and base only, no floating digits (used for the icons)
logo-dark*                 recoloured for dark backgrounds
logo-black-on-white / logo-white-on-black   one-colour versions (tube interiors are paper-coloured fills;
                           delete them in your vector editor if you need pure knockouts)
icon-square-* / icon-circle-*          app / avatar tiles (head-only composition)
favicon-*                  square tiles down to 16 px

Notes
-----
- The artwork is detailed; it reads well down to about 96 px tall. Below 48 px the tubes
  merge into texture, so a simplified favicon may still be worth having.
- Source resolution was 486 x 584 px; the trace smooths the scan but small wobbles in the
  tubes come from the original print.
